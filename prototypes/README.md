# Prototypes

Same structure as [`../components/`](../components/), but for parts still being tested. Nothing here is customer-ready.

## Categories

`panels/`, `mounts/`, `accessories/`, `rgb-lighting/` (identical to `components/`).

## Naming convention

`<category>-<part-name>_proto-<n>.<ext>`, e.g. `mounts-headset-hook_proto-3.stl`

Log what changed and why in a short `<part>-notes.md` (fit issues, print failures, tolerance adjustments). When a prototype is approved, promote it to `components/`.
